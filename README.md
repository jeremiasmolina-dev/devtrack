# DevTrack
Proyecto personal en desarrollo para practicar Python y SQL. La idea es una app de consola para hacer seguimiento de mis cursos, proyectos y objetivos.

## Estado actual
- Diseño de la base de datos,
- conexión desde Python
- Menú interactivo
- ver/agregar/actualizar en cursos, proyectos y objetivos.

## Próximos pasos
- Validación de entradas.
- Estadísticas de progreso

## Base de datos
Tablas: `cursos`, `objetivos`, `proyectos`

## Requisitos
- Python 3
- MySQL
- `pip install mysql-connector-python`

## Notas
Cambiar los datos de conexión (usuario y contraseña) en el código antes de ejecutar.
